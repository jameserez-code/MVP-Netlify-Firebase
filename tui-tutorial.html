Terminal UI Guide

The TUI is a keyboard-native operational console. No browser required — full control from the terminal.

Launch

npm run tui

Requires the server running (start with npm run demo in another terminal). The install script auto-launches both.

Keyboard Shortcuts

KeyAction
j / ↓Move selection down
k / ↑Move selection up
EnterInspect selected item — opens detail pane
EscDismiss detail pane
TabSwitch panel (Queue → Agents → Events)
dToggle detail on/off
rRetry (run) selected task
sSeed 3 demo tasks
:Enter command mode
qQuit (or Ctrl+C)

Command Palette

Press : to enter command mode. Available commands:

CommandAction
retry <id>Rerun a specific task
fail <id>Manually fail a run
seedCreate 3 demo tasks
diagRefresh all data
agentsSwitch to agents panel
queueSwitch to queue panel
eventsSwitch to events panel
helpShow command list

Demo Walkthrough

A 3-minute keyboard-driven demo:

s — seed 3 demo tasks

j j Enter — select a task, inspect it

Esc r — dismiss detail, retry (run) the task

Tab Tab Enter — switch to events, inspect an event

: seed Enter — create more tasks via command

Health model: The status indicator in the header shows HEALTHY (green), DEGRADED (amber) if there are stuck/failed tasks, or STALLED (red) if the queue is backing up. Run GET /health for details.
