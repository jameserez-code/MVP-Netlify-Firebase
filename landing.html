Passport Agent

Execution infrastructure for AI agents.
Cryptographic identity. Policy enforcement. Deterministic replay. Immutable audit.

Operator Console GitHub

What It Does

Every AI agent tool call goes through an 11-step enforcement engine before execution. The system cryptographically proves which agent made the call, checks it against defined policies, and either allows, denies, or modifies the action — all logged immutably.

Identity

Every agent gets a cryptographic keypair and passport. Every action is HMAC-signed. Unsigned or forged actions are rejected before execution.

Enforcement

Defined policies block tools, domains, and data patterns. 11-step deterministic evaluator catches SSRF, PII leaks, blocked tools — before execution.

Audit

Every tool call, state transition, and policy decision is logged with timestamps. Replay any run. Prove exactly what happened. SOC 2 ready.
