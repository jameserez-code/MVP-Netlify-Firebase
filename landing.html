Execution infrastructure for AI agents. Cryptographic identity. Policy enforcement. Deterministic replay. Immutable audit.

Open Operator Console GitHub
What It Does

Every AI agent tool call goes through an 11-step enforcement engine before execution. The system cryptographically proves which agent made the call, checks it against defined policies, and either allows, denies, or modifies the action — all logged immutably. Worker crash recovery, idempotent execution, retry with backoff, and deterministic replay come built-in.

🔒

Identity

Every agent gets a cryptographic keypair and passport. Actions are HMAC-signed. Forged actions rejected.

⛔

Enforcement

Defined policies block tools, domains, and data patterns. 11-step evaluator catches SSRF, PII leaks, blocked tools.

📋

Audit

Every tool call, state transition, and policy decision logged with timestamps. Replay any run. Prove exactly what happened.
