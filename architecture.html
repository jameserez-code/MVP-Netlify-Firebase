State Machines

Task:  pending → queued → running → completed
                          ↘ failed → pending (retry)
                          ↘ cancelled

Run:   starting → running → completed
                        ↘ failed
                        ↘ timed_out

11-Step Enforcement Engine

1. Agent status check      ─── revoked/suspended? → DENY
2. Blocked tools check      ─── in deniedTools? → DENY
3. Allowed tools check      ─── not in allowedTools? → DENY
4. Modify transforms        ─── apply parameter rewrites
5. Domain blocklist         ─── matches *.evil.com? → DENY
6. Domain allowlist         ─── no match? → DENY
7. Parameter constraints    ─── type/enum/pattern/length/range
8. Data restrictions        ─── PII / secret patterns detected? → DENY
9. Rate limit check         ─── exceeded? → DENY
10. Cost limit check        ─── exceeded? → DENY
11. Issue gateway ticket    ─── single-use JWT, 30s TTL

Deployment Modes

DEMO:    npm run demo       → localhost:3000
         JSON file store   → ~/.passport-agent/data.json
         Zero config       → auto-seeds demo data
         Worker included   → tasks execute automatically

PROD:    npm run dev        → localhost:3000
         Firestore          → real persistence
         Env vars           → FIREBASE_PROJECT_ID, etc.
         Separate worker    → npm run worker
