How Verification Works

1. Any service receives a passport number + API key from a user

2. Calls POST /api/verify-passport — no auth required

3. Passport Agent hashes the key, compares to stored hash — never exposes plaintext

4. Returns verified scopes, or denial reason with audit trail ID
