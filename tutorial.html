Web Console Tutorial

This guide walks through the complete Passport Agent workflow — from registering an agent to executing tasks with enforcement.

1

Start the server

npm run demo

Opens http://localhost:3000 in demo mode — no Firebase required.

2

Open the Operator Console

Navigate to /operator.html. This is your operational control surface. You'll see live stats, a pending queue, and an execution timeline.

3

Register an Agent

Open /agents.html. Fill in the form:

Name: Support Bot
Model: gpt-4o
Provider: openai

Click Register Agent. The server generates a cryptographic keypair and passport number. The secret key is shown once — copy it.

4

Create a Policy

In agents.html, scroll to the policy section. Create a policy that defines what your agent can do:

Allowed tools: lookup_order, check_inventory
Denied tools: send_email, delete_record
Allowed domains: *.internal.com
Blocked domains: *.evil.com, 169.254.169.254

This policy blocks the agent from sending emails or accessing internal AWS metadata — even if the LLM is tricked.

5

Execute a Task

Go back to the Operator Console. Click Seed Demos to create sample tasks, then click Run on any pending task.

The worker picks it up, creates a run, executes it (simulated), and marks it complete. Every step is logged.

6

Test Enforcement

In agents.html, use the Test Enforcement section. Try:

Tool: send_email, Params: {"to":"evil@evil.com"}

Result: DENY (tool_explicitly_blocked). The system blocked the action before execution.

Now try:

Tool: lookup_order, Params: {"orderId":"1","ssn":"123-45-6789"}

Result: DENY (pii_detected). PII patterns detected in parameters.

7

Inspect Decisions

Use GET /explain/:id to understand why a decision was made:

curl http://localhost:3000/explain/{intentId}

The response shows the full execution path: which rules were checked, which matched, which triggered, and the final decision.

Key insight: Every action an agent takes goes through an 11-step enforcement engine. The system blocks dangerous actions before execution, logs everything immutably, and can replay any run to verify outcomes. Even if an LLM is prompt-injected, the enforcement layer blocks the tool call.
